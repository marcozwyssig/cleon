== Bausteinsicht
Die Bausteinsicht zeigt das System aus einer Black-Box-Perspektive. Sie zeigt das System als eine Menge von Komponenten (Bausteinen) und deren Schnittstellen. Die Bausteine sind die Elemente, die zur Implementierung des Systems verwendet werden. Die Bausteinsicht bildet die Grundlage für die Laufzeit- und Verteilungssichten.
