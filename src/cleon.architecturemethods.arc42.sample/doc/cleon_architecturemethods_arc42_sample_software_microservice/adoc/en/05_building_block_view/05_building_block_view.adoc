== Building Block View
The building block view shows the system from a black box perspective.
It shows the system as a set of components (building blocks) and their interfaces.
The building blocks are the elements that are used to implement the system.
The building block view is the basis for the runtime and deployment views.


The following diagrams shows an overview of the main building blocks:
