== Einführung und Ziele
Die Einleitung der Architekturdokumentation sollte die treibenden Kräfte auflisten, die Softwarearchitekten bei ihren Entscheidungen berücksichtigen müssen. Dazu gehört einerseits die Erfüllung der funktionalen Anforderungen der Stakeholder, andererseits die Einhaltung der erforderlichen Randbedingungen, stets unter Berücksichtigung der Architekturziele.
