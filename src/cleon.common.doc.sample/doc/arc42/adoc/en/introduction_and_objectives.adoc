== Introduction and objectives
The introduction of the architecture documentation should list the driving forces that software architects must consider when making decisions. This includes, on the one hand, meeting the functional requirements of the stakeholders and, on the other hand, adhering to the necessary boundary conditions, always taking the architectural goals into account.
